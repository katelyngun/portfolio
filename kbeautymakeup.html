Case Study

K-Beauty Makeup

An e-commerce website renovation

kbeautymakeup.comVisit ↗

Role

Web Designer + Developer

Tools

Shopify, HTML, CSS, JavaScript

Overview

K-Beauty Makeup is a Shopify store for Korean makeup and skincare. I renovated the site through its code with one big idea in mind: a store that feels fresh, modern, and effortless to shop. Clear navigation and a clean UI help shoppers find what they want faster, which makes for a better experience and more purchases for the business.

Problem

The site felt dated and hard to navigate. When shoppers can't easily find products, they leave, and the business loses sales.

Solution

A clean, modern UI with intuitive navigation that creates a concise shopping experience, guiding shoppers from browsing to checkout and encouraging purchases.
